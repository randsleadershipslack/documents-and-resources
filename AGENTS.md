Notes for coding agents (and humans) working in this repository.

## What this is

The public, member-facing documents for the Rands Leadership Slack (RLS):
community guidelines, the incident process, onboarding guides, and the
inclusive-language word list used by the community Slackbot. `README.md` is the
index; keep it in sync when a document is added, renamed, or removed.

Everything is published under CC0 (see `LICENSE`).

## Rules

- **This repo is public.** Every file and every commit message is readable by
  anyone. Never add names of reported or sanctioned members, incident details,
  member contact data, internal admin discussion, or links to private tools or
  repositories.
- **A merge to `main` is a policy change.** Slack and the README link straight
  to these files on `main`, so whatever lands there is what members read as the
  current rules. Policy wording is decided by the RLS admins; contributions
  arrive as pull requests.
- **Edits are surgical.** Fix what was asked; don't reflow, restyle, or
  rewrite surrounding text. These documents have a deliberate voice.
- **No WORKLOG.md here.** Some contributors' tooling expects a session worklog
  in every repo; this one deliberately has none, because a public diary of
  policy changes is not something to publish. Commit messages carry the history:
  keep them plain and factual.
- **Keep links working.** Other places link to these filenames; renaming a file
  breaks those links. Avoid renames, and update `README.md` if one is required.
- `RandsInclusiveLanguage.tsv` is consumed by a bot -- keep it tab-separated
  with the existing column layout.
